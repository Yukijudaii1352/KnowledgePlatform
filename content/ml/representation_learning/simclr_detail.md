## 📝 一句话总结

SimCLR 通过**数据增强组合 + 非线性投影头 + NT-Xent 对比损失 + 大 batch**四大要素，在不需要特殊架构或记忆库的前提下，将自监督表征学习的 ImageNet 线性评估准确率提升至 76.5%（匹配监督 ResNet-50），系统性地揭示了对比学习各组件的作用机制。

## 🎯 核心要点

| # | 要点 | 细节 |
|---|------|------|
| 1 | **数据增强组合是关键** | 单一增强不足以学到好表征；**随机裁剪 + 颜色扰动**的组合最为关键——裁剪后的 patch 共享相似颜色分布，若不加颜色扰动，网络会利用颜色直方图"走捷径" |
| 2 | **非线性投影头大幅提升表征质量** | 在 encoder 输出 h 和对比损失之间加一个 MLP 投影头 g(·)：非线性 > 线性(+3%) > 无投影(+10%)。关键洞察：**下游任务应使用 h 而非 z=g(h)**，因为 z 被训练为对变换不变，丢失了有用信息 |
| 3 | **对比学习需要更强的增强和更大的 batch** | 增强强度从 1/8 到 1(+Blur)，SimCLR 准确率从 59.6% 升至 64.5%，而监督学习反而从 77.0% 降至 75.4%。Batch size 从 256 增至 8192 带来显著提升 |
| 4 | **NT-Xent 损失 + 温度缩放** | 使用归一化嵌入的温度缩放交叉熵损失，优于其他对比损失变体（NT-Logistic、Margin Triplet 等） |
| 5 | **更大模型对无监督学习收益更大** | 增加 ResNet 深度/宽度时，无监督与监督之间的差距缩小，表明自监督表征学习从大模型中获益更多 |

### 算法伪代码

```
Algorithm 1: SimCLR 算法

输入: batch size N, 温度 τ, 增强分布 T, encoder f, 投影头 g, 训练轮数 epochs

for epoch in range(epochs):
    for minibatch {xₖ} (k=1..N):
        # 1. 数据增强：对每个样本生成两个增强视图
        for k in range(N):
            t ~ T, t' ~ T                    # 采样两个随机增强
            x̃₂ₖ₋₁ = t(xₖ)                   # 第一个增强视图
            x̃₂ₖ = t'(xₖ)                     # 第二个增强视图

        # 2. 前向传播
        for i in range(2N):
            hᵢ = f(x̃ᵢ)                       # 提取表征 (ResNet输出)
            zᵢ = g(hᵢ)                        # 投影到对比空间 (MLP)

        # 3. 计算 NT-Xent 损失
        for i in range(2N):
            for j in range(2N), j ≠ i:
                sᵢⱼ = zᵢᵀzⱼ / (‖zᵢ‖·‖zⱼ‖)  # 余弦相似度
            # 正样本对 (i,j) 来自同一原始图像
            ℓᵢⱼ = -log[ exp(sᵢⱼ/τ) / Σₖ₌₁²ᴺ 𝟙[k≠i] exp(sᵢₖ/τ) ]

        L = (1/2N) Σ [ℓ(2k-1,2k) + ℓ(2k,2k-1)]  # 对称损失

        # 4. 反向传播更新 f 和 g 的参数
        update(f, g, ∇L)                      # LARS optimizer

# 推理时丢弃 g，仅用 f 的输出 h 作为表征
return encoder f
```

### 方法详解

#### 1. 对比学习的"任务定义"——数据增强的核心作用

SimCLR 的核心洞察之一是：**数据增强本质上定义了对比学习的预测任务**。传统方法通过修改网络架构（如限制感受野实现 global-to-local 预测）来定义任务，而 SimCLR 证明简单的随机裁剪就能涵盖这些任务——裁剪可以产生全局到局部视图（大裁剪 vs 小裁剪）或相邻视图（两个不重叠的裁剪区域）。

关键发现是**增强的组合远比单一增强重要**。实验表明（Figure 5），单独使用任何一种增强（如仅裁剪或仅颜色变换），模型虽然能完美解决对比任务，但学到的表征质量很差。原因在于：单一增强定义的任务太简单，网络可以利用"捷径"（如颜色直方图）来区分正负样本，而无需学习语义特征。随机裁剪 + 颜色扰动的组合之所以最有效，是因为裁剪后的 patch 天然共享相似的颜色分布，加入颜色扰动后迫使网络必须依赖更高层的语义信息来完成对比任务。

此外，对比学习需要比监督学习**更强**的数据增强（Table 1）：增强强度增加时 SimCLR 持续受益（59.6% → 64.5%），而监督学习反而退化（77.0% → 75.4%）。这表明对比学习的正则化需求与监督学习有本质不同。

#### 2. 投影头——信息瓶颈的巧妙利用

SimCLR 的第二个关键发现是非线性投影头 g(h) = W⁽²⁾σ(W⁽¹⁾h) 的重要性。实验显示（Figure 8）：使用非线性投影头比不使用投影头提升超过 10% 的线性评估准确率。

更深刻的洞察在于：**下游任务应使用投影前的表征 h，而非投影后的 z = g(h)**。z 的线性评估准确率比 h 低 10% 以上。作者对此的解释是：对比损失训练 z 对数据变换保持不变性，这个过程会丢弃对下游任务有用的信息（如物体颜色、朝向等）。投影头 g 充当了一个**信息瓶颈**：它吸收了对比任务所需的不变性约束，使得 h 能保留更丰富的信息。

实验验证了这一假说（Table 3）：用 h 预测训练时施加的变换类型（如旋转角度）的准确率远高于用 g(h) 预测，证明 h 确实保留了更多关于变换的信息。这一发现对后续所有对比学习方法都产生了深远影响——几乎所有后续工作都采用了"训练时用投影后的 z 计算损失，推理时用投影前的 h 作为表征"这一范式。

#### 3. 大 Batch + NT-Xent 损失——对比学习的训练策略

SimCLR 使用 NT-Xent（Normalized Temperature-scaled Cross Entropy）损失，其核心公式为：

$$\ell_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(z_i, z_k)/\tau)}$$

其中 sim(u,v) = uᵀv/(‖u‖‖v‖) 是余弦相似度，τ 是温度参数。与其他对比损失（如 NT-Logistic、Margin Triplet）相比，NT-Xent 的优势在于：(1) 使用 ℓ₂ 归一化的嵌入，使得损失对表征的尺度不敏感；(2) 温度参数 τ 有效控制了对困难负样本的关注程度——较低的 τ 使模型更关注与正样本相似的困难负样本。

大 batch size 对 SimCLR 至关重要，因为每个 batch 中的其他样本都充当负样本。Batch size 从 256 增至 8192 时性能持续提升。这与使用记忆库（memory bank）的方法形成对比——SimCLR 证明只要 batch 足够大，就不需要额外的记忆库来存储负样本。训练使用 LARS 优化器，在 128 个 TPU v3 核心上以 batch size 4096 训练 100 epochs。

## 🧪 练习题

### Q1: 为什么 SimCLR 中随机裁剪必须与颜色扰动组合使用？

<details>
<summary>💡 答案</summary>

因为随机裁剪产生的不同 patch 天然共享相似的颜色分布（来自同一图像的不同区域颜色统计接近）。如果只用裁剪而不加颜色扰动，网络可以仅通过匹配颜色直方图就轻松区分正负样本对，而无需学习真正的语义特征。加入颜色扰动后，颜色信息被破坏，迫使网络必须依赖更高层的语义信息（如物体形状、纹理等）来完成对比任务，从而学到更有泛化性的表征。

</details>

### Q2: 为什么 SimCLR 在推理时使用投影头之前的表征 h，而非之后的 z = g(h)？

<details>
<summary>💡 答案</summary>

对比损失训练 z 对数据增强变换保持不变性（invariance），这意味着 z 会主动丢弃与变换相关的信息（如颜色、朝向、裁剪位置等）。然而这些信息对下游任务可能是有用的。投影头 g 充当信息瓶颈，吸收了不变性约束的"代价"，使得其输入 h 能保留更丰富、更通用的信息。实验验证：h 预测变换类型的准确率远高于 g(h)，且 h 的线性评估准确率比 z 高 10% 以上。

</details>

### Q3: 如果将 SimCLR 的 batch size 从 8192 减小到 256，你预期会发生什么？有什么替代方案？

<details>
<summary>💡 答案</summary>

性能会显著下降，因为每个正样本对只有 (2×256-2)=510 个负样本，对比任务变得过于简单，难以学到区分性强的表征。替代方案包括：(1) **记忆库**（MoCo 方法）：维护一个负样本队列，解耦 batch size 和负样本数量；(2) **动量编码器**（MoCo）：用指数移动平均更新的编码器生成一致的负样本表征；(3) **更长的训练**：SimCLR 论文也表明更长的训练可以部分弥补小 batch 的不足；(4) **BYOL/SimSiam 等方法**：完全不依赖负样本，通过其他机制（如停止梯度、预测器）避免表征坍缩。

</details>

### Q4: NT-Xent 损失中温度参数 τ 的作用是什么？τ 过大或过小会怎样？

<details>
<summary>💡 答案</summary>

温度 τ 控制了 softmax 分布的"锐度"，即模型对困难负样本的关注程度：
- **τ 过小**（如 0.01）：softmax 分布极其尖锐，梯度几乎完全由最困难的负样本（与正样本最相似的负样本）主导。这可能导致训练不稳定，且容易受到假负样本（实际是同类但被当作负样本）的干扰。
- **τ 过大**（如 1.0）：softmax 分布趋于均匀，所有负样本被同等对待，模型无法有效区分困难和简单负样本，学习效率低下。
- **最优 τ**（SimCLR 中为 0.1 或 0.5）：在关注困难负样本和训练稳定性之间取得平衡。此外，τ 与 ℓ₂ 归一化配合使用——归一化后余弦相似度范围为 [-1, 1]，τ 的缩放效果更加可控。

</details>
