## 📝 一句话总结

ALERTCalifornia是UC San Diego运营的加州全州级公共安全项目，通过部署1200+台高清PTZ摄像头网络并结合深度学习AI烟雾/火焰检测系统，实现野火15分钟内自动发现，首季即检测1200+起火灾且30%以上早于911报警，被TIME评为2023年度最佳发明。

---

## 🎯 核心要点

- **大规模传感器网络**: 加州全境部署1200+台高清PTZ摄像头，每台每2分钟完成360°全景扫描（12帧高清图像），白天可视距离60英里，夜间近红外模式可达120英里
- **AI火灾检测系统**: 与CAL FIRE和Digital Path合作开发的深度学习烟雾/火焰识别系统，2023年9月部署至全部21个CAL FIRE 911调度中心，输出火灾置信度百分比和估计位置
- **检测性能**: 基于Govil等人的原型系统，可在点火后15分钟内检测到烟雾，每台摄像头每天误报不到1次；首季运行检测1200+起火灾，30%以上早于911电话报警
- **多模态感知演进**: 从可见光HD摄像头→红外热成像（穿透烟雾/雾霾）→实验性高光谱摄像头（10GB/次采集，可检测含水量、吸收光谱、阴燃火灾指标、空气质量）
- **20年技术积累**: 2001年HPWREN无线网络→2003年Cedar Fire实战验证→ALERTWildfire多校联盟→ALERTCalifornia第三代全州系统，2019-2023年摄像头数量翻倍
- **人机协同工作流**: AI检测→watchstander（值班员）人工确认→消防调度响应，减少值班员疲劳、降低误报、在火灾萌芽阶段即可扑灭

### 3. AI 检测算法核心流程 (基于Govil et al., 2020)

```
算法: 基于深度学习的野火烟雾检测
输入: 摄像头实时图像流 I_t (每台每2分钟12帧)
输出: 火灾警报 {位置, 置信度, 时间戳}

伪代码:
───────────────────────────────────────
1. FOR each camera c in Camera_Network:       // 遍历1200+摄像头
2.   FOR each frame f in Sweep(c):            // 每次扫描12帧
3.     I_curr ← capture(c, f)                 // 当前帧
4.     I_ref  ← get_reference(c, f)           // 历史参考帧(同角度)
5.     
6.     // ---- 图像预处理 ----
7.     ΔI ← temporal_difference(I_curr, I_ref)  // 时序差分检测变化
8.     ROI ← extract_candidate_regions(ΔI)      // 提取候选异常区域
9.     
10.    // ---- 深度学习分类 ----
11.    FOR each region r in ROI:
12.      features ← CNN_extract(r)              // 卷积特征提取
13.      p_smoke ← classifier(features)         // 烟雾概率
14.      p_fire  ← classifier(features)         // 火焰概率
15.      
16.      IF max(p_smoke, p_fire) > τ_alert:     // 超过告警阈值
17.        loc ← triangulate(c, r, DEM)         // 基于DEM地形三角定位
18.        alert ← {camera: c, confidence: p,
19.                  location: loc, time: now()} 
20.        send_to_dispatch(alert)               // 发送至911调度中心
21.        
22. // ---- Watchstander 确认 ----
23. IF watchstander.confirm(alert):
24.   dispatch_fire_resources(alert)            // 调度消防资源
25. ELSE:
26.   log_false_positive(alert)                 // 记录误报用于模型优化
───────────────────────────────────────
```

### 4. 关键技术方法论

#### 4.1 时序差分与异常检测

系统利用同一摄像头同一角度的历史参考图像与当前图像进行差分比较，检测场景中的新增异常（烟雾柱、火焰光斑）。这种方法可有效过滤静态背景（山脉、植被、建筑），聚焦于动态变化：

$$\Delta I(x,y) = |I_{t}(x,y) - I_{ref}(x,y)| > \theta_{change}$$

其中 $I_t$ 为当前帧，$I_{ref}$ 为参考帧（可为前一扫描周期或长期平均），$\theta_{change}$ 为变化检测阈值。

#### 4.2 深度学习烟雾/火焰分类

基于卷积神经网络(CNN)的图像分类器，对候选区域进行烟雾/火焰/正常三分类。Govil等人的系统实现了：
- **检测速度**: 点火后15分钟内检测到烟雾
- **误报率**: 每台摄像头每天 < 1次误报
- **扫描能力**: 云端工作流每分钟可扫描数百台摄像头

$$P(fire|patch) = \text{softmax}(W \cdot \text{CNN}(patch) + b)$$

#### 4.3 多源融合策略

系统设计为地面摄像头与卫星检测的互补融合：
- **地面摄像头优势**: 高空间分辨率、快速响应（分钟级）、夜间红外能力
- **卫星检测优势**: 大范围覆盖（如GOES卫星）、不受地形遮挡
- **融合目标**: 结合两者优势实现全覆盖、快响应的检测体系

**设计理念**:
- AI负责7×24小时不间断监测，解决人工值班员疲劳问题

- 目标是在火灾"萌芽阶段"(incipient phase)即发现并扑灭
- 对偏远地区异常检测尤其有效，夜间表现突出
