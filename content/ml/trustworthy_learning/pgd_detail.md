# Towards Deep Learning Models Resistant to Adversarial Attacks

## 元信息
| 字段 | 内容 |

## TL;DR
将对抗鲁棒性形式化为鞍点(min-max)优化问题，证明PGD（Projected Gradient Descent）是"万能"一阶攻击方法，并通过PGD对抗训练+增大网络容量，在MNIST和CIFAR10上训练出对一阶攻击具有可证明鲁棒性的深度学习模型。

## 问题背景
深度神经网络对对抗样本（adversarial examples）极其脆弱——输入上微小的、人眼不可察觉的扰动即可导致模型错误分类。此前的防御方法（如FGSM对抗训练）仅对弱攻击有效，面对多步迭代攻击时完全失效。核心挑战在于：
1. **攻击建模不完备**：缺乏对"最强攻击者"的形式化定义，导致防御评估不可靠
2. **优化困难**：对抗训练的内层最大化问题被认为难以求解
3. **容量不足**：标准网络架构可能缺乏同时保持准确性和鲁棒性的能力

## 方法

### 核心思想
将对抗鲁棒性问题统一为**鞍点优化框架**：外层最小化模型参数以降低"对抗损失"，内层最大化寻找最强对抗样本。关键洞察是：对于神经网络的损失曲面，内层最大化问题的局部极大值高度集中（loss值差异极小），因此PGD可以可靠地找到近似最优解，从而成为"万能一阶攻击者"。

### 关键公式/算法

**鞍点公式（核心优化目标）：**
$$\min_\theta \rho(\theta), \quad \text{where} \quad \rho(\theta) = \mathbb{E}_{(x,y)\sim\mathcal{D}}\left[\max_{\delta \in \mathcal{S}} L(\theta, x+\delta, y)\right]$$

其中 $\mathcal{S} = \{\delta : \|\delta\|_\infty \leq \epsilon\}$ 为允许的扰动集合。

**PGD攻击（内层求解器）：**
$$x^{t+1} = \Pi_{x+\mathcal{S}}\left(x^t + \alpha \cdot \text{sgn}(\nabla_x L(\theta, x^t, y))\right)$$

- $\Pi_{x+\mathcal{S}}$：投影到以原始样本 $x$ 为中心的 $\ell_\infty$ 球上
- $\alpha$：步长
- 从 $x + \mathcal{S}$ 内的随机点启动

**对抗训练（外层求解器）：**
使用SGD优化模型参数，梯度在PGD找到的对抗样本处计算。理论依据为Danskin定理：内层最大化器处的梯度即为鞍点问题的有效下降方向。

### 设计选择与理由

| 设计选择 | 理由 |
|----------|------|
| 使用PGD而非FGSM作为训练攻击者 | FGSM是单步攻击，网络会"过拟合"到FGSM产生的受限对抗样本集，对多步攻击无鲁棒性（label leaking现象） |
| 随机初始化启动PGD | 实验发现不同随机起点收敛到的局部极大值loss值高度一致，说明单次随机重启的PGD已足够 |
| 增大网络容量 | 对抗鲁棒分类需要更复杂的决策边界（需分离 $\ell_\infty$ 球而非单点），小容量网络被迫牺牲自然准确率 |
| 训练时每batch仅运行一次PGD（不重启） | 多epoch训练中每个样本会被多次遇到，等效于多次随机重启 |
| 使用 $\text{sgn}(\nabla)$ 而非原始梯度 | 在 $\ell_\infty$ 约束下，符号梯度是最优的一阶更新方向，且简化步长选择 |

## 实验

### 实验设置
- **数据集**：MNIST（$\epsilon=0.3$）、CIFAR10（$\epsilon=8/255$）
- **MNIST架构**：2层卷积（32, 64 filters）+ FC(1024)，PGD训练40步，步长0.01
- **CIFAR10架构**：ResNet的10×宽变体（16, 160, 320, 640 filters），PGD训练7步，步长2
- **评估攻击**：白盒PGD（不同步数/重启数）、CW攻击、黑盒迁移攻击

### 主要结果

**MNIST（$\epsilon=0.3$）：**

| 攻击方法 | 准确率 |
|----------|--------|
| 自然样本 | 98.8% |
| FGSM白盒 | 95.6% |
| PGD-40白盒 | 93.2% |
| PGD-100×20重启白盒 | **89.3%** |
| CW白盒 | 94.0% |
| PGD-100×20黑盒(A') | 95.7% |

**CIFAR10（$\epsilon=8$）：**

| 攻击方法 | 准确率 |
|----------|--------|
| 自然样本 | 87.3% |
| FGSM白盒 | 56.1% |
| PGD-20白盒 | **45.8%** |
| CW-30白盒 | 46.8% |
| PGD-7黑盒(A') | 64.2% |
| PGD-7黑盒(自然训练) | 86.0% |

### 消融/分析

1. **容量影响**：MNIST上将网络容量从1×扩大到16×，PGD训练后对抗准确率从接近0提升到有意义水平；CIFAR10上宽ResNet比标准ResNet对抗准确率从43.7%→45.8%
2. **Loss landscape分析**：对MNIST和CIFAR10的loss曲面进行可视化，发现：(a) 不同随机起点的PGD收敛到的loss值高度集中；(b) 大量随机重启未能发现显著更高的loss值
3. **训练方法对比**：
   - 标准训练：容量增大仅略微提升对FGSM的鲁棒性，对PGD无效
   - FGSM训练：对大$\epsilon$产生label leaking，对PGD攻击无鲁棒性
   - PGD训练：唯一能产生对多步攻击鲁棒性的方法
4. **跨范数泛化**：$\ell_\infty$训练的模型对$\ell_2$攻击也有一定鲁棒性，但PGD可能高估$\ell_2$鲁棒性（梯度遮蔽效应）

## 贡献与局限

### 主要贡献
1. **理论框架**：将对抗鲁棒性严格形式化为鞍点优化问题，为后续研究奠定统一基础
2. **实证发现**：证明PGD是"万能一阶攻击者"——loss landscape的局部极大值高度集中
3. **方法论**：提出PGD对抗训练作为可靠的防御方法，对所有一阶攻击提供鲁棒性保证
4. **容量洞察**：首次系统证明网络容量是对抗鲁棒性的关键因素

### 局限性
1. **计算开销大**：PGD对抗训练需要在每个batch上运行多步攻击，训练成本比标准训练高数倍至数十倍
2. **自然准确率下降**：CIFAR10上自然准确率从95.2%降至87.3%，存在accuracy-robustness trade-off
3. **仅限一阶攻击**：理论保证仅覆盖一阶（梯度基）攻击者，对零阶或更高阶攻击无形式化保证
4. **$\ell_2$鲁棒性高估**：MNIST模型学到的阈值滤波器导致梯度遮蔽，PGD无法有效攻击但模型并非真正鲁棒
5. **CIFAR10鲁棒性仍不理想**：白盒PGD-20下仅45.8%准确率，距实用仍有差距

## 个人思考

1. **范式奠基意义**：本文确立了"PGD攻击+对抗训练"作为对抗鲁棒性研究的标准范式（攻击用PGD评估、防御用AT训练），后续几乎所有工作都在此框架上展开。其核心贡献不仅是方法本身，更是将问题形式化为可优化的数学框架。

2. **"万能一阶攻击者"的局限**：论文的核心假设——loss landscape局部极大值集中——是实证观察而非严格证明。后续工作（如AutoAttack）表明，即使在一阶范畴内，更精细的攻击策略组合仍能进一步降低模型准确率。

3. **容量-鲁棒性关系的深层含义**：论文揭示的"鲁棒分类需要更大容量"这一发现，暗示了对抗鲁棒性可能是一个本质上更困难的学习问题（需要学习更复杂的函数类），这与后续的理论工作（如sample complexity of robust learning）相呼应。

4. **梯度遮蔽问题的预警**：论文诚实地报告了$\ell_2$评估中PGD失效的现象，这实际上预示了后续大量"虚假鲁棒性"（obfuscated gradients）问题的出现，也说明仅依赖梯度基攻击评估防御方法的危险性。

5. **与后续发展的连接**：本文直接催生了TRADES（更好的accuracy-robustness平衡）、Free/FGSM-RS AT（降低计算成本）、AWP（权重空间扰动）等重要后续工作，是对抗鲁棒性领域最重要的奠基性论文之一。
