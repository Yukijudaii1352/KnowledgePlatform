Pearl以Haavelmo的结构方程思想为起点，系统阐述了结构因果模型(SCM)如何通过do-算子、反事实定义和图模型工具，将因果推断从参数化线性模型推广到完全非参数化框架，实现因果效应的算法化识别。

### 算法伪代码：Haavelmo干预操作与因果效应识别

```
算法: SCM因果效应计算 (Causal Effect via Intervention)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

输入: 结构因果模型 M = <U, V, F>, 干预变量 X, 目标变量 Y, 干预值 x
输出: P(y | do(x)) — 干预后Y的分布

步骤:
1. 构建修改模型 M_x:
   - 从 F 中删除 X 的结构方程 f_X
   - 添加常数方程 X = x
   - 保留所有其他方程不变

2. 图形化识别 (Back-door准则):
   IF 存在变量集 Z 满足:
     (a) Z 中无 X 的后代节点
     (b) Z 阻断 X 与 Y 之间所有后门路径 (在 G 中)
   THEN:
     P(y|do(x)) = Σ_z P(y|x, z) · P(z)    // 调整公式
     RETURN 可识别估计量

3. 若 Back-door 不适用, 应用 do-calculus 三规则:
   规则1 (插入/删除观测):
     P(y|do(x), z, w) = P(y|do(x), w)
     条件: (Y ⊥ Z | X, W)_{G_{\overline{X}}}

   规则2 (动作/观测交换):
     P(y|do(x), do(z), w) = P(y|do(x), z, w)
     条件: (Y ⊥ Z | X, W)_{G_{\overline{X}, \underline{Z}}}

   规则3 (插入/删除动作):
     P(y|do(x), do(z), w) = P(y|do(x), w)
     条件: (Y ⊥ Z | X, W)_{G_{\overline{X}, \overline{Z(S)}}}
     其中 S = An(W)_{G_{\overline{X}}}

4. 若所有规则均无法化简 do(·):
   RETURN "不可识别"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
完备性: 对递归模型, do-calculus 是完备的 (Huang & Valtorta, 2006;
        Shpitser & Pearl, 2006)
```

### 方法解释

#### 第一段：Haavelmo的干预思想与SCM的形式化

Pearl追溯了因果推断的思想源头至Haavelmo 1943年的开创性论文。Haavelmo的核心洞见是：结构方程不仅描述变量间的统计关联，更编码了数据生成的因果机制。当政府通过政策干预将收入固定在某一水平时，这等价于用常数方程替换收入的原始结构方程，同时保持系统中其他方程不变。这一"方程替换"操作被Pearl形式化为do-算子：$P(y \mid do(x))$ 表示在强制设定 $X=x$ 后观察 $Y$ 的概率分布。

形式化地，结构因果模型(SCM)定义为三元组 $M = \langle U, V, F \rangle$，其中 $U$ 是外生(不可观测)变量集，$V$ 是内生(可观测)变量集，$F$ 是结构函数集。每个内生变量 $v_i$ 由其结构方程 $v_i = f_i(pa_i, u_i)$ 决定，其中 $pa_i \subseteq V \setminus \{v_i\}$ 是 $v_i$ 的直接原因(父节点)。当外生变量相互独立时，该模型可用有向无环图(DAG)表示，其中节点代表变量，有向边代表直接因果关系。

#### 第二段：反事实的结构定义与潜在结果的统一

论文的核心贡献之一是Definition 1——单位水平反事实的结构定义。给定完全指定的结构模型 $M$，反事实 $Y_x(u)$（"若X被设为x，单位u的Y值"）定义为修改模型 $M_x$ 中Y的解，其中 $M_x$ 通过将X的方程替换为 $X=x$ 而得到，外生变量保持在 $U=u$：

$$Y_x(u) \triangleq Y_{M_x}(u)$$

这一定义建立了SCM与Neyman-Rubin潜在结果框架之间的桥梁。关键区别在于：在SCM中，反事实和"可忽略性"(ignorability)等假设可以从模型结构中推导出来，无需作为外部假设单独施加。每个结构方程 $y = f(x, \epsilon)$ 自动携带反事实信息：$Y_x(u) = f(x, \epsilon(u))$，同时编码排除限制(exclusion restrictions)——未出现在方程右侧的变量对Y无直接因果效应。

#### 第三段：非参数识别与因果演算的完备性

论文展示了SCM框架最强大的实用价值：即使在完全非参数化设定下（函数形式和分布均未知），仅凭图结构中编码的定性假设（排除限制+因果马尔可夫条件），就能判定因果效应是否可从观测数据中识别，并给出具体的统计估计量。

核心工具包括：(1) **Back-door准则**：若存在变量集Z满足不含X后代且阻断所有后门路径，则 $P(y|do(x)) = \sum_z P(y|x,z)P(z)$；(2) **d-separation**：从图结构直接读取条件独立性，无需知道函数形式；(3) **do-calculus三规则**：一组完备的图形化推导规则，可将任何可识别的因果量化简为纯观测量的函数。

Shpitser和Pearl(2008)证明了对任意非参数三角联立方程模型，存在有效算法判定因果效应是否可识别——这意味着非参数识别问题已被完全解决。这体现了Marschak极大值原理的终极实现：政策问题的回答往往不需要估计系统中的每个参数，甚至不需要指定函数形式。

#### 第四段：与经济学传统的联系与超越

Pearl指出，阻碍Cowles委员会（约1950年）做出下一步逻辑推进的两个关键缺失成分是：原则1（结构反事实法则，即Definition 1的"擦除"操作）和原则2（结构独立性法则，即d-separation定理）。这两个原则直到1980-90年代才被发展出来。

论文还回应了Lucas批判：如果干预改变了预测其效果的方程本身怎么办？Pearl论证这实际上是查询误指定(query misspecification)问题——如果干预I（旨在将X从x改为x'）对其他变量有副作用，正确的查询应是 $P(y|do(I))$ 而非 $P(y|do(x'))$，以考虑I的各种副作用。查询正确指定的责任在于查询提供者，而非模型本身。

## 🧪 练习题

### 基础题

**Q1**: 在SCM中，$P(y|x)$ 与 $P(y|do(x))$ 的本质区别是什么？请用一个具体例子说明两者可能不同。

<details>
<summary>参考答案</summary>

$P(y|x)$ 是条件概率，表示在观察到 $X=x$ 的群体中 $Y=y$ 的比例，可能受混杂因素影响（如共同原因Z同时影响X和Y）。$P(y|do(x))$ 是干预概率，表示强制设定 $X=x$ 后 $Y=y$ 的概率，切断了所有指向X的因果路径。

**例子**：设Z=吸烟习惯，X=携带打火机，Y=肺癌。观察到携带打火机的人肺癌率更高（$P(cancer|lighter)$ 高），但强制让人携带打火机不会导致肺癌（$P(cancer|do(lighter))$ 不变），因为吸烟是共同原因。
</details>

**Q2**: 给定DAG: $Z \rightarrow X \rightarrow Y$，$Z \rightarrow Y$，请判断：(a) Z是否满足X对Y因果效应的back-door准则？(b) 写出调整公式。

<details>
<summary>参考答案</summary>

(a) 检查back-door准则：Z不是X的后代 ✓；Z阻断X与Y之间的后门路径。在此图中，X→Y是前门路径，Z→X→Y也是前门路径，Z→Y是从Z到Y的直接路径。后门路径是从X出发经过指向X的箭头到达Y的路径。此图中X没有后门路径（没有箭头指向X除了Z→X），而Z→X→Y不是后门路径。唯一的后门路径是 X←Z→Y，Z阻断了它。所以Z满足back-door准则 ✓

(b) 调整公式：$P(y|do(x)) = \sum_z P(y|x, z) \cdot P(z)$
</details>

### 进阶题

**Q3**: 考虑Pearl论文中的Model 1（图2(a)），解释为什么集合 $\{W_1, Z_3\}$ 满足X对Y因果效应的back-door准则，而单独的 $\{Z_3\}$ 不满足。

<details>
<summary>参考答案</summary>

在Model 1的DAG中：
- X对Y的后门路径包括经过 $W_1$ 和 $Z_3$ 的路径
- $\{W_1, Z_3\}$ 满足：(a) 两者都不是X的后代 ✓；(b) 它们共同阻断了X与Y之间所有后门路径 ✓
- 单独 $\{Z_3\}$ 不满足：因为存在经过 $W_1$ 的后门路径 $X \leftarrow W_1 \leftarrow Z_1 \rightarrow Z_3 \rightarrow Y$ 未被 $Z_3$ 单独阻断（条件化Z3可能打开对撞路径）

具体而言，$Z_3$ 是X的父节点之一（$X = g(W_1, Z_3, U')$），条件化 $Z_3$ 后仍有路径 $X \leftarrow W_1 \leftarrow Z_1 \rightarrow Z_3$（但Z3已被条件化）需要仔细分析d-separation。加入 $W_1$ 确保所有后门路径被阻断。
</details>

**Q4**: 请用Definition 1的反事实定义，解释为什么结构方程 $Y = aX + \epsilon_1$ 中的排除限制(exclusion restriction)意味着 $Y_{xz}(u) = ax + \epsilon_1(u)$（即Z对Y无直接效应），并说明这一假设是否可以通过实验检验。

<details>
<summary>参考答案</summary>

根据Definition 1，$Y_{xz}(u)$ 表示在修改模型 $M_{x,z}$ 中Y的解，其中X的方程被替换为 $X=x$，Z的方程被替换为 $Z=z$。

由于Y的结构方程为 $Y = aX + \epsilon_1$，其中Z不出现在右侧，因此无论Z被设为什么值，Y的方程仍然只依赖X和 $\epsilon_1$。在 $M_{x,z}$ 中，Y的解为 $Y = ax + \epsilon_1(u)$，与z无关。

因此 $Y_{xz}(u) = ax + \epsilon_1(u) = Y_x(u)$，这就是排除限制的反事实含义。

**可检验性**：排除限制可以通过干预实验检验——同时控制X=x并改变Z的值，观察Y是否变化。如果 $P(Y|do(x), do(z)) = P(Y|do(x), do(z'))$ 对所有z, z'成立，则排除限制得到支持。
</details>
