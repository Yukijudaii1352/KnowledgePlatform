## 📝 一句话总结

t-SNE 通过在低维空间使用重尾的 Student-t 分布（替代高斯分布）来建模点对相似度，有效解决了高维→低维映射中的**拥挤问题**（crowding problem），成为高维数据可视化的标杆方法。

## 🎯 核心要点

### 1. 解决的问题
- **高维数据可视化**：将高维数据（如784维的MNIST手写数字）映射到2D/3D空间进行可视化
- **拥挤问题**：当高维空间降至低维时，中等距离的点被"挤压"到近邻区域，导致簇结构无法分辨
- **SNE的缺陷**：原始SNE使用非对称KL散度、高斯分布建模低维空间，优化困难且可视化质量差

### 2. 核心创新

| 创新点 | 原始SNE | t-SNE |
|--------|---------|-------|
| 高维相似度 | 条件概率 $p_{j \mid i}$（非对称） | 联合概率 $p_{ij} = \frac{p_{j \mid i} + p_{i \mid j}}{2n}$（对称） |
| 低维分布 | 高斯分布 | **Student-t 分布**（1自由度，即Cauchy分布） |
| 代价函数 | $\sum_i KL(P_i \| Q_i)$ | 单一 $KL(P \| Q)$ |
| 梯度形式 | 复杂，含 $\sum$ 项 | 简洁统一的"吸引-排斥"形式 |

### 3. 关键公式

**高维联合概率**（基于高斯核）：

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}$$

$$p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}$$

**低维联合概率**（基于Student-t分布）：

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l}(1 + \|y_k - y_l\|^2)^{-1}}$$

**代价函数**（KL散度）：

$$C = KL(P \| Q) = \sum_{i} \sum_{j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

**梯度**：

$$\frac{\partial C}{\partial y_i} = 4 \sum_j (p_{ij} - q_{ij})(y_i - y_j)(1 + \|y_i - y_j\|^2)^{-1}$$

### 4. 效果

- 在 MNIST、Olivetti Faces、COIL-20 等数据集上**显著优于** Sammon mapping、Isomap、LLE
- MNIST 6000样本上，t-SNE 2D表示的1-NN分类错误率仅 5.13%（原始784维为 5.75%）
- 能清晰分离不同类别，同时揭示类内变化结构

### 算法伪代码

```
算法: t-SNE (t-distributed Stochastic Neighbor Embedding)

输入: 数据集 X = {x_1, ..., x_n}
      代价函数参数: 困惑度 Perp
      优化参数: 迭代次数 T, 学习率 η, 动量 α(t)

输出: 低维表示 Y = {y_1, ..., y_n}

步骤:
1. 对每个数据点 x_i，用二分搜索找到 σ_i 使得 Perp(P_i) = Perp
2. 计算条件概率 p_{j|i}（基于高斯核和 σ_i）
3. 对称化: p_{ij} = (p_{j|i} + p_{i|j}) / (2n)
4. 初始化: Y^(0) ~ N(0, 10^{-4} I)
5. FOR t = 1 TO T:
     a. 计算低维联合概率 q_{ij}（基于 Student-t 分布）
     b. 计算梯度: dC/dy_i = 4 Σ_j (p_{ij} - q_{ij})(y_i - y_j)(1+||y_i-y_j||²)^{-1}
     c. 更新: Y^(t) = Y^(t-1) + η·(dC/dY) + α(t)·(Y^(t-1) - Y^(t-2))
   END FOR

优化技巧:
- 早期夸大 (Early Exaggeration): 前50次迭代将 p_{ij} 乘以4，鼓励形成紧密簇
- 早期压缩 (Early Compression): 对 y_i 施加L2惩罚，使初始映射点聚拢
- 自适应学习率: η = 100（远大于常规值）
- 动量切换: α = 0.5 (前250次) → 0.8 (之后)
```

### 详细解析

#### 一、从SNE到t-SNE：拥挤问题的本质与解决

t-SNE 的核心贡献在于识别并解决了**拥挤问题（crowding problem）**。这个问题的本质是高维空间与低维空间之间的**体积不匹配**。在 $m$ 维空间中，距离中心点 $r$ 处可容纳的点数与 $r^m$ 成正比。当从高维（如 $m=30$）降至二维时，原本在中等距离处的大量点在低维空间中没有足够的"面积"来安置，被迫挤入近邻区域，导致不同簇的边界模糊。

原始 SNE 在低维空间也使用高斯分布建模 $q_{ij}$，高斯分布的尾部衰减极快（指数级），这意味着低维空间中稍远的点对几乎没有排斥力，无法有效"推开"不同簇的点。t-SNE 的关键洞察是：**在低维空间使用重尾的 Student-t 分布**。Student-t 分布（1自由度，即 Cauchy 分布）的概率密度函数为 $(1 + \|y_i - y_j\|^2)^{-1}$，其尾部以多项式速率衰减（而非指数级），这为中等距离的点对提供了更大的 $q_{ij}$ 值。这样，原本在高维空间中处于中等距离的点可以在低维空间中被映射到更远的位置，而不会产生过大的代价，从而为近邻簇腾出空间。

从梯度角度理解，t-SNE 的梯度 $\frac{\partial C}{\partial y_i} = 4\sum_j (p_{ij} - q_{ij})(y_i - y_j)(1 + \|y_i - y_j\|^2)^{-1}$ 可以解读为一个 N-body 模拟系统：当 $p_{ij} > q_{ij}$ 时产生吸引力（将低维点拉近），当 $p_{ij} < q_{ij}$ 时产生排斥力（将低维点推远）。因子 $(1 + \|y_i - y_j\|^2)^{-1}$ 确保了远距离点对的排斥力不会过大，使优化过程稳定。

#### 二、对称化与困惑度：局部自适应的邻域定义

t-SNE 的另一个重要设计是**自适应的局部邻域**。每个数据点 $x_i$ 拥有独立的高斯核带宽 $\sigma_i$，通过二分搜索确定，使得条件概率分布 $P_i$ 的困惑度（perplexity）等于用户指定的值。困惑度定义为 $\text{Perp}(P_i) = 2^{H(P_i)}$，其中 $H(P_i)$ 是 $P_i$ 的香农熵。困惑度可以粗略理解为每个点的"有效邻居数"，典型值为 5-50。在数据密度高的区域，$\sigma_i$ 较小（邻域紧凑）；在稀疏区域，$\sigma_i$ 较大（邻域宽松）。这种自适应机制使 t-SNE 能够同时处理密度差异极大的数据区域。

对称化处理 $p_{ij} = (p_{j|i} + p_{i|j})/(2n)$ 将非对称的条件概率转化为联合概率，带来两个好处：（1）简化代价函数为单一 KL 散度，梯度更简洁；（2）确保每个数据点对映射结果有最低限度的贡献——即使 $x_i$ 是一个离群点，$\sum_j p_{ij} \geq 1/(2n)$，避免离群点在映射中完全被忽略。

#### 三、优化策略与大规模扩展

t-SNE 的代价函数是**非凸**的，优化结果依赖于初始化和超参数选择。论文提出了多个实用技巧：**早期夸大**（前50次迭代将 $p_{ij}$ 乘以4）迫使低维空间中的 $q_{ij}$ 也必须很大才能匹配，这促使相似的点快速聚拢形成紧密簇，为后续的精细调整提供良好初始结构；**早期压缩**（对 $y_i$ 施加L2正则化）防止初始阶段点分散过远；**动量从0.5切换到0.8**帮助优化跳出局部最优。

对于大规模数据集（$n > 10000$），标准 t-SNE 的 $O(n^2)$ 复杂度不可接受。论文提出了**随机游走版本**：选取一组地标点（landmark points），在全数据的邻域图上执行随机游走来计算地标点之间的相似度 $p_{ij}$。与 Isomap 的最短路径不同，随机游走整合了所有路径的信息，对"短路"噪声更鲁棒。实验表明，使用全部60000个MNIST样本的信息来可视化6000个地标点，仅需1小时CPU时间。

#### 四、局限性与后续发展

论文坦诚讨论了三个局限：（1）t-SNE 主要设计用于 $d=2,3$ 的可视化，对于 $d>3$ 的降维任务，Cauchy 分布的重尾可能过于极端，需要使用更高自由度的 Student-t 分布；（2）t-SNE 基于局部线性假设，对**内在维度过高**的数据（如人脸图像空间约100维）效果可能下降；（3）非凸优化导致结果不确定性，但实践中不同运行的质量差异不大。后续工作中，Barnes-Hut t-SNE（2014）将复杂度降至 $O(n \log n)$，UMAP（2018）提供了更快的替代方案，参数化 t-SNE 则通过神经网络实现了对新数据的泛化能力。

## 🧪 练习题

### 题目1：拥挤问题的本质
**t-SNE 解决的"拥挤问题"（crowding problem）的根本原因是什么？**

- A. 高维数据中存在太多噪声维度
- B. 高维空间中可用体积随距离呈指数增长，低维空间增长慢得多，导致中等距离的点在低维中被挤压
- C. 高斯核的带宽选择不当导致所有点看起来距离相同
- D. KL散度的不对称性导致远距离点对被过度惩罚

**答案：B**

> 解析：拥挤问题的本质是维度导致的体积不匹配。在 $m$ 维空间中，距离 $r$ 处可容纳的点数正比于 $r^m$。从高维降至2维时，原本分布在中等距离处的大量点在低维空间中缺乏足够的面积来安置，被迫挤入近邻区域。A选项描述的是维度灾难的另一个方面；C和D虽然是SNE的问题，但不是拥挤问题的根因。

### 题目2：Student-t 分布的作用
**t-SNE 在低维空间使用 Student-t 分布（而非高斯分布）的主要效果是什么？**

- A. 使计算复杂度从 $O(n^3)$ 降低到 $O(n^2)$
- B. 使低维空间中距离较远的点对仍有较大的概率值，从而允许不同簇之间保持更大间距
- C. 消除了对困惑度（perplexity）超参数的依赖
- D. 使代价函数变为凸函数，保证全局最优

**答案：B**

> 解析：Student-t 分布（Cauchy分布）的重尾特性意味着低维空间中较远的点对仍有相对较大的 $q_{ij}$ 值。这允许高维中处于中等距离的点在低维中被映射到更远的位置而不产生过大代价，为近邻簇腾出空间。A不正确，复杂度仍为 $O(n^2)$；C不正确，困惑度仍需设置；D不正确，t-SNE代价函数是非凸的。

### 题目3：对称化的意义
**t-SNE 将条件概率 $p_{j|i}$ 对称化为联合概率 $p_{ij} = (p_{j|i} + p_{i|j})/(2n)$ 的一个重要好处是什么？**

- A. 消除了对高斯核带宽 $\sigma_i$ 的需求
- B. 使得代价函数变为凸函数
- C. 确保每个数据点（包括离群点）对代价函数有最低限度的贡献，即 $\sum_j p_{ij} \geq 1/(2n)$
- D. 将时间复杂度从 $O(n^2)$ 降低到 $O(n \log n)$

**答案：C**

> 解析：对称化后 $\sum_j p_{ij} = 1/(2n) \cdot \sum_j (p_{j|i} + p_{i|j})$，由于 $\sum_j p_{j|i} = 1$，所以 $\sum_j p_{ij} \geq 1/(2n)$。这保证了即使是离群点也不会在映射中被完全忽略。A不正确，$\sigma_i$ 仍需通过困惑度确定；B不正确，代价函数仍非凸；D不正确，复杂度不变。

### 题目4：早期夸大的作用
**t-SNE 优化中"早期夸大"（early exaggeration）技巧的目的是什么？**

- A. 增大学习率以加速收敛
- B. 在优化初期将 $p_{ij}$ 乘以一个大于1的因子，迫使相似点快速聚拢形成紧密簇，为后续精细调整提供良好初始结构
- C. 随机打乱数据点的顺序以避免局部最优
- D. 逐步增加困惑度以实现从粗到细的多尺度优化

**答案：B**

> 解析：早期夸大在前50次迭代中将所有 $p_{ij}$ 乘以4，使高维相似度被人为放大。为了最小化 KL 散度，低维空间中的 $q_{ij}$ 也必须相应增大，这迫使相似的点快速靠近形成紧密、分离良好的簇。这为后续去除夸大因子后的精细优化提供了优良的初始布局。A描述的是学习率设置；C和D不是t-SNE使用的技巧。
