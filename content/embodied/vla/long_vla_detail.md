### 论文概述

**标题**: Long-VLA: Enhancing Long-Horizon Vision-Language-Action Models with Decomposition and Adaptive Masking

**作者**: Minjie Fan, Yifan Fan, Zicheng Zhang, Yifei Dong, Jianlan Luo, Mingyu Ding, Yang Gao, Wei Zhan

**发表信息**: CoRL 2025 (Proceedings of Machine Learning Research, v305)

**论文链接**: https://proceedings.mlr.press/v305/fan25a.html

---

#### 核心思想

Long-VLA 针对**长序列（Long-Horizon）具身任务**中视觉-语言-动作（Vision-Language-Action, VLA）模型的性能退化问题，提出了两阶段层次化分解与自适应输入掩码策略。
论文的核心出发点源于一个关键观察：长序列任务可以按照操作语义自然地分解为**移动阶段**（Moving Phase）和**交互阶段**（Interaction Phase），两个阶段对视觉输入的依赖模式有本质差异——移动阶段需要依赖第三人称静态相机进行物体导航，而交互阶段则要关注末端执行器相机的精细视图以应对视觉分布偏移。
然而，传统VLA模型（如MDT）将整条轨迹视为同质序列处理，导致长序列下性能骤降（从单步任务93.3%降至五步任务51.1%）。
Long-VLA通过以下三个模块实现突破：
**(1)** 阶段分解数据集构建与统一动作表示扩展（增加相位标识符sp）；
**(2)** 基于二元掩码矩阵M的Phase-Aware Masking机制，在注意力计算层面动态选择性调制视觉token，不改变输入结构；
**(3)** 联合条件扩散动作解码与对比语言-视觉目标对齐损失。
在CALVIN仿真基准上，Long-VLA在10步任务序列上将基线方法成功率从11%提升至20%（81%相对增益），在真实机器人实验中同样验证了其有效性。

---

### 核心解决的问题

1. **长序列性能退化**：现有VLA模型无法同时满足多模态令牌规模膨胀（O(N^2)注意力代价）与长时间依赖保持之间的矛盾，随着任务序列增长，策略执行误差累积导致失败率指数上升。
2. **跨阶段视觉分布偏移**：移动阶段和交互阶段的视觉输入特征截然不同，统一处理导致模型在阶段切换时产生动作预测偏差。
3. **移动-交互策略耦合**：先前工作[3]需要借助逆运动学（IK）实现精确运动轨迹，但获取精确3D目标与实用IK解在真实场景中往往不可行，需要端到端的学习策略替代IK。

### 核心方法

#### 1. 阶段分解与数据构建

##### 1.1 移动-交互双阶段分解

论文首先通过预实验验证了层次化分解的有效性。在CALVIN数据集上，将每个子任务细分为**移动阶段（Moving Phase）**和**交互阶段（Interaction Phase）**：

- **移动阶段**：机器人抓取末端执行器从当前位置运动到目标物体附近，需要依赖静态第三人称相机进行空间导航。
- **交互阶段**：机器人执行精细操作（如按下按钮、抓取物体），需要关注末端执行器相机的局部视图。

分解后的轨迹表示为：
```
tau = { (s^M_t, a^M_t)_{t in [0, d]}, (s^I_t, a^I_t)_{t in [d+1, T]} }
```
其中 **d** 为切割时间步。切割点设置在**物体状态变化前10-15帧**，确保阶段对齐。语言指令通过基于检测到的物体和位置的运动特定命令进行增强。

##### 1.2 预实验验证

| 方法 | 任务序列完成率（%） |
|:---|:---:|
| **序列长度** | **1 / 2 / 3 / 4 / 5** |
| MDT [52] | 93.3 / 82.4 / 71.9 / 60.9 / 51.1 |
| MDT + MP（分离移动策略） | **95.8 / 91.7 / 87.5 / 66.7 / 54.2** |

*表格来源：论文Table 1*

分离训练移动策略后，所有序列长度的任务完成率均有提升，验证了分解策略的有效性，但训练两个独立模型缺乏可扩展性。

##### 1.3 统一动作表示扩展

为实现端到端统一框架训练，Long-VLA将原始动作表示从7维扩展为8维，增加一维**相位标识符 sp**：

```
a_t = [x, y, z, eu_x, eu_y, eu_z, s_g, s_p]
```

- **(x, y, z)**：末端执行器笛卡尔坐标
- **(eu_x, eu_y, eu_z)**：欧拉角方向表示
- **s_g**：夹爪状态（开/关）
- **s_p**：相位标识符，**-1**表示移动阶段，**1**表示交互阶段；推理时初始化为-1

#### 2. Phase-Aware Masking 自适应输入策略

##### 2.1 设计动机

论文论证指出：
- **移动阶段**：末端执行器相机视图信息量极小，模型应聚焦于静态第三人称相机进行精确物体导航。
- **交互阶段**：视觉分布偏移加剧，注意力应转移到末端执行器相机视图以实现精确操作。

基于此提出**输入级自适应策略**，通过掩码机制动态调整视觉输入——**不直接移除整个模态**，而是在注意力计算层面选择性激活token。

##### 2.2 算法：Phase-Aware Self-Attention with Binary Mask Matrix

```
算法：Phase-Aware Self-Attention with Binary Mask Matrix

输入:
  - 查询 Q in R^{N×C}，键 K in R^{N×C}，值 V in R^{N×C}
  - 二元掩码向量 m in {0,1}^N （m_i = 1 表示第 i 个 token 参与注意力计算）
  - 当前阶段相位 sp in {-1, 1}

步骤:
  1. 根据 sp 生成掩码向量 m:
     若 sp = -1（移动阶段）:
       将末端执行器相机 token 位置设为 0，其他保持 1
     若 sp = 1（交互阶段）:
       将静态相机 token 中冗余部分选择性设 0，末端执行器相机 token 保持 1

  2. 构造注意力掩码矩阵 M in {0,1}^{N×N}:
     for i = 1 to N:
         for j = 1 to N:
             M_{ij} = m_i * m_j

  3. 计算缩放点积相似度矩阵 P:
     P = Q K^T / sqrt(C)

  4. 计算掩码注意力权重 A:
     for i = 1 to N:
         for j = 1 to N:
             A_{ij} = exp(P_{ij}) * M_{ij} / sum_{k=1}^N exp(P_{ik}) * M_{ik}

  5. 输出掩码注意力输出 H:
     H = A V

输出: 相位感知的自注意力输出 H in R^{N×C}
```

*公式编号对应论文Equation (1)*

##### 2.3 掩码机制的关键特性

- **保持模态一致性**：不改变输入token序列的结构和数量，仅通过注意力层面的掩码实现选择性聚焦。
- **平滑注意力分布**：通过mask后重新归一化（分母仅对活跃token求和），保证注意力权重在有效token间平滑分布。
- **无缝阶段切换**：相位变化时仅修改掩码向量m，模型无需重新初始化或加载不同参数，实现端到端连续推理。

#### 3. 训练范式与优化目标

##### 3.1 条件扩散动作解码

Long-VLA采用**条件扩散模型**生成动作 a_t，通过DDIM采样进行反向去噪过程：

```
x_{t-1} = (sigma_{t-1} / sigma_t) * x_t - (-h) * e^{-1} * x_hat_0
```

扩散训练损失为标准分数匹配损失，**联合监督**移动和交互两个阶段：

```
L_Diff = E_{a~p_data} E_{n~N(0, sigma^2 I)} || D_theta(a_tilde, e_post, sigma_t) - a_t ||_2^2
```

其中 D_theta(a_tilde, e_post, sigma_t) 为动作去噪器，输入噪声动作 a_tilde、多模态编码特征 e_post 和噪声水平 sigma_t。

##### 3.2 对比语言-视觉目标对齐损失

为保证视觉目标与语言指令的**语义一致性**，引入InfoNCE对比损失 L_Goal（详见附录C.2）：

```
L = L_Diff + alpha * L_Goal
```

其中超参数 alpha 设为 **0.1**。

##### 3.3 联合端到端训练

Long-VLA在分解后的L-CALVIN数据集上进行端到端训练，同时使用文本指令和视觉目标（未来观测 s_{t+n}）作为多模态条件。训练时两个阶段的损失共同反向传播，梯度通过共享的多模态编码器、动作解码器流经所有参数。

#### 4. 模型架构详解

##### 4.1 观察编码器 (Observation Encoder)

- 采用可训练的**ResNet-18**将两种视觉输入编码为潜空间特征：
  - s^t_g（末端执行器相机视图）-> 特征 e_g
  - s^t_b（静态第三人称相机视图）-> 特征 e_b

##### 4.2 目标编码器 (Goal Encoder)

- 利用**冻结的CLIP模型**编码多形式目标：
  - 语言指令 -> e^l_goal（文本编码器）
  - 未来观测 s_{t+n} -> e^o_goal（图像编码器）
- 策略类似MDT[52]，未标注轨迹数据使用视觉目标，标注数据使用语言指令

##### 4.3 检测集成 (Detection Integration)

- 在CALVIN子集上**LoRA微调Grounding DINO**实现细粒度物体定位
- 检测模型 f_d 基于语言查询预测像素级边框
- 通过可训练位置编码器将边框投影到潜空间，得到检测特征 e_d
- 采用**FiLM调制策略**将 e_d 注入静态相机特征，生成检测增强的表示 e_b_hat

##### 4.4 多模态编码器 (Multimodal Encoder)

- 基于**GPT-2风格Transformer**架构
- 输入特征拼接：e_pre = [e_b_hat; e_g; e_goal; e_d]
- 输出潜空间感知令牌 e_post

##### 4.5 动作解码器 (Action Decoder)

- 条件扩散模型生成最终动作
- 通过**两层MLP（GELU激活）**将扩散输出去噪映射为8维动作向量

---

#### 关键结果3：消融研究

论文通过消融实验验证各模块的贡献（详见Section 4）：

- **去除Phase-Aware Masking**：退化为统一输入处理，长序列性能显著下降，证明跨阶段视觉选择性聚焦的必要性。
- **去除检测集成（Detection Integration）**：物体导航精度下降，尤其在物体密集场景中。
- **去除目标对齐损失（L_Goal）**：语言指令与视觉目标语义一致性减弱，导致错误选择目标物体。

---

#### 关键结果4：真实世界实验

- **方块放置任务（8步序列）**：Long-VLA成功完成长序列操作，在放置8个不同方块时无累积误差失败。
- **厨房清洁任务（4步序列）**：验证了复杂动作执行能力，包括按钮按压、物体抓取、放置入水槽等多重交互类型。

### 局限性分析与改进方向

#### 1. 阶段切割点的启发式设定

论文将切割点设定为"物体状态变化前10-15帧"，依赖于先验知识或手动标注。
**改进方向**：可引入自动阶段检测模块（如基于state change的时序分割模型），利用物体状态描述（VLM检测）自动学习最优切割点，减少人工干预并适配更复杂任务结构。

#### 2. 相位标识符的硬切换机制

当前sp在{-1, 1}之间硬切换，缺乏对阶段过渡区域的平滑建模。在移动->交互的临界帧附近，两种视觉输入可能都具有参考价值。
**改进方向**：引入软相位权重（连续值 sp in [-1,1]），在过渡区域启用双相机融合，或通过学习自回归预测下一时刻的sp来实现更流畅的阶段转换。

#### 3. 检测模型的领域依赖性

Grounding DINO以LoRA微调于CALVIN子集，在真实世界或新物体类别上的泛化能力有限。
**改进方向**：可采用开放词汇检测器（如OWL-ViT、Detic）增强检测通用性，或结合3D点云信息来补偿2D检测的深度歧义。

#### 4. 扩散推理延迟

条件扩散模型虽然精度高，但DDIM多步采样推理延迟（通常10-100步去噪）对于高频闭环控制的实时性构成挑战。
**改进方向**：可蒸馏为一致性模型（Consistency Model）或采用Flow Matching架构，将去噪步数降至1-5步而不显著损失精度。

#### 5. 任务分解粒度限定为两级

当前固定为移动-交互两阶段，对更复杂的任务（如"移动到抽屉->打开抽屉->移动到物体->抓取物体->移动到目标->放置"）需要更细粒度的分解。
**改进方向**：扩展到层次化多阶段分解（如移动-接近-交互-撤离），结合Task-and-Motion Planning（TAMP）自动生成阶段图。

#### 6. 实验评估局限于桌面操作场景

所有评估均在CALVIN桌面环境和类似场景的真实操作中进行，未涉及移动操作、多房间导航或人机交互场景。
**改进方向**：在更复杂的具身环境（如Habitat、BEHAVIOR-1K）中评估，验证多阶段分解在多场景迁移中的鲁棒性。

| **Octo** (Team et al.) | 2023 | 大规模机器人基础模型 | 与Long-VLA互补的规模化路线 |
| **Groot**等VLA Scaling Law | 2024 | 数据/模型规模与性能关系 | Long-VLA从结构创新（分解+掩码）而非规模化角度突破 |

#### 可关联的跨领域概念

1. **Multi-Task Learning中的Task-Specific Attention**：类似于MMoE（Multi-gate Mixture-of-Experts）中为不同任务学习不同的门控网络，Long-VLA通过相位感知掩码实现了类条件下的"视觉模态门控"。

2. **Spatiotemporal Action Segmentation**：视频理解中的动作分割（如MS-TCN, ASFormer）研究如何自动检测细粒度动作边界，该方法可为Long-VLA的阶段自动分割提供技术支持。

3. **Conditional Computation**：Sparsely-Gated MoE、Switch Transformer等动态激活部分网络参数的思想，与Long-VLA的选择性token参与注意力计算在本质上都是"给定条件下的稀疏前向传播"。

4. **Hierarchical Reinforcement Learning (HRL)**：高层策略选择子目标，低层策略执行具体动作的两层架构，Long-VLA的移动-交互分解可视作两层策略在单模型中的隐式实现。

5. **Embodied Multi-Modal Alignment**：CLIPort、PerAct等方法探索语言、视觉、动作间的对齐，Long-VLA的InfoNCE目标对齐损失延续了该研究方向。
